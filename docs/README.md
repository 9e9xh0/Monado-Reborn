# Monado documentation

English is the canonical language for developer documentation. The one Spanish player-facing guide is
[`user/es/README.md`](user/es/README.md); older Spanish records are archived under [`history/es/`](history/es/).
See [CONTRIBUTING.md](../CONTRIBUTING.md) for the documentation-language rule.

## Current status

- Task ledger (what is done and what is open): [`dev/tasks.md`](dev/tasks.md).
- Session prose (English) goes to [`dev/CHANGELOG.md`](dev/CHANGELOG.md).
- Every edit to the inherited LASRecomp runtime: [`UPSTREAM.md`](UPSTREAM.md).
- Session handoffs are historical and archived in [`dev/archive/`](dev/archive/); the last one is
  [`dev/archive/HANDOFF-2026-10-25.md`](dev/archive/HANDOFF-2026-10-25.md).
- HLE classification: [`hle_audit.md`](hle_audit.md), generated by `tools/hle_audit.py` (CI-checked).

## Layout

```
docs/
├── README.md              this index
├── adr/                   architecture decisions, one per file + README index
├── contracts/             design contracts cited by the code and tests
├── dev/                   development record: spec, plan (frozen), research (frozen), tasks, CHANGELOG
│   └── archive/           historical session handoffs and work logs
├── evidence/              milestone evidence (M0–M4) and dated task evidence
├── guides/                build, Linux, PGO, lifter and cheats guides
├── history/               archived records, kept for context and not maintained
│   ├── audits/            external/initial technical audits and phase records
│   ├── es/                Spanish originals of documents now maintained in English
│   ├── plans/             historical design/research plans (party mod, low-end GPU)
│   ├── port/              port validation reports (Spanish, historical)
│   ├── releases/          release-notes memo (Spanish, historical)
│   └── research/          one-off research dumps and reviews of other projects
├── reference/             dump inventory, NSO stats and cross-project knowledge base
├── user/es/README.md      Spanish player guide (the only maintained Spanish doc)
├── PERFORMANCE_UI.md      performance profiles and interface (user guide)
├── VULKAN_DLSS_FPS.md     Vulkan path, DLSS and FPS overlay (user guide)
├── UPSTREAM.md            local changes to the inherited runtime (article X)
└── hle_audit.md           generated HLE classification (article VI)
```

## Checking the documentation

`python3 tools/check_docs.py` validates local Markdown links and backticked repo-relative paths against the tracked
files. It runs in `scripts/ci.sh` and in CI; broken documentation paths fail the check.
